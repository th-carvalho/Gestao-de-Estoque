# Gestao-de-Estoque
Gerenciador de estoque e vendas para pequenos negócios — frontend em React com Tailwind. Backend e banco de dados em desenvolvimento.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
